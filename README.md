# შოთა & ქეთი — საქორწილო მოსაწვევი

გაუშვით პროექტის საქაღალდიდან: `python3 -m http.server 8080 --directory dist`
შემდეგ გახსენით http://localhost:8080

არ საჭიროებს ინსტალაციას ან build-ს. `dist/` მზადაა სტატიკური ჰოსტინგისთვის (მათ შორის Vercel).

კარიბჭე იხსნება მხოლოდ ღილაკით. საწყისი სცენა იყენებს მოწოდებულ ოქროს კარიბჭის ფოტოს ცალკე 3D ფრთებითა და ჩარჩოთი. შემდეგ ჩნდება მოწოდებული ბაღის ცერემონიის ფოტო კამერის მიახლოებით. ფოტოზე ადამიანები სტატიკურია; ეს არ არის პერსონაჟების სიარულის ანიმაცია. Reduced-motion რეჟიმი მხარდაჭერილია. მუსიკა ბრაუზერში სინთეზირებული ინსტრუმენტული მელოდიაა, მხოლოდ ღილაკით ირთვება. უკუთვლის სამიზნე: 14 ნოემბერი 2026, 13:00, UTC+04:00.

გალერეა შეიცავს მომხმარებლის მოწოდებულ საცნობარო სურათებს; ეს არ არის წყვილის პირადი ფოტოგალერეა. პირადი ფოტოებით ჩასანაცვლებლად შეცვალეთ dist/assets და index.html-ის შესაბამისი აღწერები. რუკები Google Maps-ის საძიებო ბმულებია მოწოდებული დასახელებებით; ზუსტი მისამართები მომხმარებელს არ მოუწოდებია.
